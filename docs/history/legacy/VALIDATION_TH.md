การทดสอบฟอร์มโหลด HTML และโค้ดจริงใน jsdom แล้วเรียกฟังก์ชันบันทึกจริง โดยจำลองบริการ Browser และไม่โหลด CDN ภายนอก จึงทดสอบข้อมูล/DOM ได้ แต่ไม่ใช่การตรวจภาพจาก Browser จริง

ผล build มีคำเตือนว่า JavaScript bundle มีขนาดเกิน 500 KB ซึ่งเป็นคำเตือนด้านขนาดไฟล์ ไม่ใช่ build error ยังไม่ได้ปรับแยกหน้าระบบเป็น lazy-loaded bundles ในรุ่นนี้

## การทดสอบที่เพิ่มใน v3.2

เพิ่ม 17 กรณีจากชุดเดิม 32 รวมเป็น 49 กรณีผ่านทั้งหมด ครอบคลุมปัญหา 6 ข้อในรายงานตรวจเชิงลึก พร้อมการกู้เอกสารที่ถูกต้อง การล็อกใบเสร็จที่มีฉบับพิมพ์แล้ว การส่งหลายรอบพร้อมเศษสตางค์ การรับเงินก่อนสร้างใบวางบิล การย้ายข้อมูล Billing เดิม การแสดงต้นทุนไม่ครบ และการลองรับสินค้าใหม่หลังเขียนล้มเหลวที่ GR/Movement/PO/Audit

ทดสอบสำเร็จใน Node.js และ DOM/IndexedDB จำลอง ไม่ได้ทดแทนการตรวจ PDF และ Browser จริง รายละเอียดการแก้และผลก่อน–หลังอยู่ใน `DEMO_V3_2_CHANGES_TH.md`

## ขอบเขตที่ยังต้องตรวจด้วยผู้ใช้งาน

- การจัดหน้าและตัวอักษรไทยใน Preview / PDF / เครื่องพิมพ์จริง
- การคลิกใช้งานจริงบนจอเล็กและ Browser ของลูกค้า
- ข้อมูลเก่าที่เคยถูกแก้มือหรือไม่มีรหัสอ้างอิงเอกสาร
- การเปิดพร้อมกันหลายแท็บ/หลายเครื่อง และ Firebase/Rules จริง
- ภาษีเฉพาะกิจการ เช่น WHT, คืนสินค้าและใบลดหนี้ ไม่อยู่ในชุดทดสอบนี้

สภาพแวดล้อมการตรวจครั้งนี้เปิด localhost ใน Browser สำหรับตรวจภาพไม่ได้ จึงรายงานผลจากการทดสอบข้อมูลและ DOM จำลองตามขอบเขตข้างต้น

## ลำดับตรวจสาธิตแนะนำ

1. Export Backup JSON ทุกปี พร้อมตรวจว่าไฟล์แนบครบ
2. ใช้ข้อมูลสมมติ สร้างสินค้า Inventory 10 ชิ้น และลูกค้าทดสอบ
3. สร้างใบเสนอราคา 10 ชิ้น อนุมัติ แล้วสร้าง SO
4. วางแผนสินค้า ตรวจยอดพร้อมใช้/ยอดจอง แล้วส่งรอบแรก 3 ชิ้น
5. ตรวจว่าค้างส่ง 7 ชิ้น และจำนวนพร้อมใช้ลดลงตามใบส่งจริง
6. รับเงินบางส่วน ตรวจยอดค้างและใบเสร็จ
7. ส่งอีก 7 ชิ้น สร้างใบวางบิล และรับเงินที่เหลือ
8. ตรวจว่า SO ปิดหลังส่งครบและรับเงินครบ และยอดขายไม่เพิ่มอีกจากใบเสร็จ
9. เปิด Preview และพิมพ์ PDF ใบเสนอราคา ใบส่งสินค้า ใบเสร็จ และใบวางบิล ตรวจชื่อบริษัท/ลูกค้า/สาขา/VAT/ยอดรวม
10. ทดลอง Export และ Import ใน Browser ทดสอบอีกโปรไฟล์ ตรวจข้อมูลและไฟล์แนบ ก่อนใช้สาธิตจริง

การรับเงินผ่านใบวางบิลสร้างใบเสร็จแยกตาม Invoice ที่จัดสรรเงิน หากต้องยกเลิก ให้ใช้ปุ่มยกเลิกในรายการรับเงินเพื่อรักษาความสัมพันธ์ของเอกสาร
