## เดินเรื่อง 10 นาที

> ขั้นที่มี ✍️ = ทำสดต่อหน้าลูกค้า (ใช้ **สาขาที่ 00001** และลูกค้า **บจก. อีสานโลจิสติกส์ เอ็กซ์เพรส** ทั้งเรื่อง)

### ก่อนเปิดเรื่อง (~1 นาที) · ใส่โลโก้และข้อมูลบริษัทลูกค้า ✍️ (ADR-020)
- **เตรียม**: ไฟล์โลโก้ของลูกค้า (PNG / JPG / WebP ไม่เกิน 5 MB — ขอทางอีเมล/LINE ก่อนวันนัด) ชื่อบริษัท ที่อยู่ และเลขประจำตัวผู้เสียภาษี 13 หลัก
- **คลิก**: ชื่อบริษัทบนหัวโปรแกรม (หรือเมนู **ตั้งค่า → ตั้งค่าบริษัท** หรือ **Demo → ข้อมูลบริษัทและโลโก้**) — อยู่ในโหมดง่ายได้เลย ไม่ต้องสลับโหมด
- ✍️ **อัปโหลดโลโก้** → พิมพ์ชื่อบริษัท ที่อยู่ เลขผู้เสียภาษี (ระบบตรวจหลักสุดท้ายให้ — ถ้าขึ้นตัวแดงให้ถามลูกค้าอีกครั้ง) → ชี้กล่อง **ตัวอย่างหัวเอกสาร** ด้านขวาที่เปลี่ยนตามทันที → **บันทึก**
- **ชี้**: หัวโปรแกรมเปลี่ยนเป็นโลโก้และชื่อลูกค้าทันที — ทุกใบที่เปิดต่อจากนี้ (ใบเสนอราคา ใบกำกับภาษี ใบเสร็จ ใบลดหนี้ และ PDF) ใช้หัวเอกสารของลูกค้า
- **พูด**: "ตั้งครั้งเดียว ลูกค้าแก้เองได้ตลอด เก็บในเครื่องนี้และอยู่ในไฟล์สำรองข้อมูล"

  (แถบแดง "มีใบแจ้งหนี้เกินกำหนด 5 ใบ …" อยู่ที่แท็บ **ลูกหนี้ค้างรับ** และหน้า **งานของฉัน**)

| ราคาเท่าไร / ติดตั้งอย่างไร | (ตอบตามข้อเสนอการขาย) — Demo นี้เปิดจากไฟล์ในเครื่องหรือเว็บทดลองได้ทันที ไม่ต้องติดตั้ง |

## หลังจบ / ก่อนลูกค้ารายถัดไป

1. ปุ่ม **Demo** มุมขวาบน → **ล้างข้อมูลสาธิตทั้งหมด (รีเซ็ต)** (รายการสีแดงล่างสุด) → อ่านข้อความ → ตกลง
   - ลบข้อมูลของระบบนี้ใน Browser เครื่องนี้ทั้งหมด (เอกสาร ลูกค้า/สินค้า การตั้งค่า เป้าขายของข้อมูลตัวอย่าง การปิดงวด Audit Log) แล้วเริ่มเหมือนติดตั้งครั้งแรก — **เป้าขาย/เป้ายอดส่งที่ตั้งเองไว้จะเก็บไว้**
   - **ไม่แตะ** ข้อมูลของเว็บ/โปรแกรมอื่นใน Browser และคงโหมดง่าย/ขั้นสูงกับหมวดเมนูที่พับไว้
   - ถ้าระหว่างสาธิตมีคนบันทึกข้อมูลจริงไว้ ระบบจะถามยืนยันครั้งที่สอง — สำรองข้อมูลก่อนถ้าจำเป็น
   - **ข้อมูลบริษัทและโลโก้ของลูกค้าคนก่อนไม่ถูกลบโดยรีเซ็ตนี้** (เป็นการตั้งค่า) — ไปที่ **ตั้งค่าบริษัท → กลับไปใช้ข้อมูลตัวอย่าง** หรืออัปโหลดของลูกค้ารายถัดไปทับ
2. **Demo → โหลดข้อมูลตัวอย่างสำหรับสาธิต** ใหม่ได้ทันที (หรือกดโหลดเลยก็ได้ ระบบจะถามว่าแทนที่ชุดเดิมไหม) วันที่จะเลื่อนตามวันนี้ อายุลูกหนี้จึงถูกต้องเสมอ

## ข้อควรรู้

- เอกสารตัวอย่าง **ไม่นับรวม** ในโควตาทดลองใช้ (Trial) — สร้างเอกสารสดระหว่างสาธิตได้ตามปกติ
- ถ้ามีการปิดงวดบัญชีครอบวันที่ของข้อมูลตัวอย่าง ระบบจะไม่โหลดและบอกให้ปลดล็อกงวดหรือรีเซ็ตก่อน (ไม่ข้ามการปิดงวด)
- ตัวเลขในสคริปต์นี้อิงข้อมูลที่เพิ่งโหลด **ก่อน** ทำขั้นตอนสด; ถ้าซ้อมแล้วไม่ได้รีเซ็ต ตัวเลขจะรวมเอกสารที่ซ้อมไว้ด้วย
